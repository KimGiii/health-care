# 식단 추천 R1 관찰용 베타 테스터 모집 계획

작성일: 2026-07-20
상태: 실행 계획
대상: 제품 기획, 운영
관련: 이슈 #85·#86, PR #84·#87, `DIET_RECOMMENDATION_ENHANCEMENT_DECISIONS_2026-06-29.md`

## 1. 배경과 목적

R1(PR #84)과 swap 계측(PR #87)이 dev에 머지됐고, 다음 의사결정은 전부 **배포 후 2주 관찰 데이터**에 걸려 있다.

- R2(매크로 밴드) vs ⓪(검증 풀 확장) 우선순위 — 판정 쿼리 3개(실패율 20% · 음식 기인 refresh 40% · 상위 10 GENERATED 점유 70% 임계)
- #85 대안 스냅샷 저장 A/B/C안 — swap 빈도·`alternative_index` 분포

문제: 현재 이 관찰을 수행할 테스터가 없다. 이 문서는 테스터 확보 방안과 소표본 보정 방침을 확정한다.

## 2. 채택안: TestFlight 외부 테스트 + 소표본 보정 (A+C안)

### A안 — TestFlight 외부 테스트

- 공개 링크 방식: 이메일 개별 초대 없이 링크 접속만으로 참여. 외부 테스터 최대 10,000명.
- 외부 테스트는 시작 전 베타 앱 심사 1회 필요(정식 심사보다 가벼움) — 리드타임에 반영할 것.
- 테스터는 TestFlight 스크린샷 피드백으로 정성 의견을 바로 남길 수 있다.
- 참고: [TestFlight 개요](https://developer.apple.com/testflight/), [외부 테스터 초대 가이드](https://developer.apple.com/help/app-store-connect/test-a-beta-version/invite-external-testers/)

### 모집 채널 (국내, 무료 순)

| 채널 | 성격 | 기대 |
|---|---|---|
| [디스콰이엇](https://disquiet.io) | 메이커·인디해커 커뮤니티, 베타 모집 글 관례화 | 프로덕트에 익숙한 테스터, 피드백 품질 높음 |
| [테스트잇](https://test.it.kr/) | 웹/앱 베타테스터 매칭 커뮤니티 | 테스트 목적이 명확한 참여자 |
| 헬스·운동 커뮤니티(네이버 카페, 오픈채팅, 에브리타임 등) | 타깃 사용자(식단 기록·바디 목표) | 실사용 패턴에 가까운 데이터 |
| [HOLA](https://holaworld.io/) · [인프런 커뮤니티](https://www.inflearn.com/community/projects) | 사이드프로젝트 커뮤니티 | 보조 채널 |
| 지인 | 즉시 가능 | 초기 스모크 검증용 |

### 모집 문구 골격

- 무엇을: 알러지·기피 식품을 등록하면 하루 식단(아침·점심·저녁·간식)을 목표 영양에 맞춰 추천하는 기능
- 요청 행동: 제한 조건 등록 → 추천 받기 → 마음에 안 들면 "다시 추천"(사유 선택) → 실제로 먹을 끼니는 기록으로 저장
- 기간: 2주 (연장 가능)
- 주의 문구: 의료적 안전을 보장하지 않으며, 등록한 제한 조건 기준 제외라는 점 명시 (PRD #66 문구 원칙 준수)

### C안 — 소표본 보정

테스터가 5~10명 수준이면 판정 임계(20%/40%/70%)를 비율 그대로 적용하기 어렵다.

- 관찰 기간 연장: 2주 → 4주
- 정성 피드백 병행: TestFlight 스크린샷 피드백 + 재추천 사유 선택 분포를 함께 해석
- 판정 쿼리는 그대로 돌리되, 표본 크기(추천 생성 수·활성 테스터 수)를 리포트에 병기해 임계 적용 여부를 그때 판단

## 3. 보류안: B안 — prod 승격 후 실사용자 관찰

표본이 가장 크지만, 미검증 기능의 실사용자 노출 리스크와 App Store 정식 심사 리드타임이 있다. **R1 스모크(추천 생성 → 이벤트 적재 → 다시 추천 → 기록 전환)가 TestFlight에서 깨끗이 통과한 뒤 재검토**한다.

## 4. 실행 순서

1. dev 백엔드 배포 + PR #84 미체크 스모크 수행 (개발자 본인)
2. 추천 기능 포함 빌드를 TestFlight 외부 테스트로 등록 → 베타 앱 심사
3. 공개 링크 발급 → 디스콰이엇·테스트잇·헬스 커뮤니티·지인 채널에 모집 글 게시
4. 관찰 시계 시작 — 주 1회 중간 점검(이벤트 적재량·실패 Counter), 2주(소표본이면 4주) 후 판정 쿼리 실행
5. 결과로 R2 vs ⓪ 우선순위 결정 + #85 A/B/C 재판정

## 5. 성공 기준

- 활성 테스터 10명 이상(미달 시 C안 연장 발동)
- 추천 생성 이벤트가 판정 쿼리를 돌릴 수 있는 규모로 적재됨
- 알러지·hard 제약 위반 신고 0건 (배포 게이트 원칙 유지)
