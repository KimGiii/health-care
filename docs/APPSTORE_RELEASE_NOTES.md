# App Store 업데이트 문구 가이드

## 작성 구조

```
[첫 줄] 이번 업데이트로 [핵심 가치]가 더 [형용사]해졌어요.

• [기능명] 추가/개선 — [사용자 관점 혜택 설명]. [부연 설명 있으면 이어서.]

• ...

의견은 언제든 환영합니다. 건강한 하루 되세요!
```

## 규칙

- **첫 줄**: 이번 업데이트의 핵심 가치를 한 문장으로 요약. "이번 업데이트로 ~가 더 ~해졌어요." 형태.
- **불릿 기호**: `•` 사용 (하이픈 `-` 아님)
- **구분자**: 기능명과 설명 사이 em dash `—` 사용
- **톤**: 친근한 경어체 (`~해요`, `~어요`). 딱딱한 문어체 금지.
- **이모지**: 사용 안 함
- **기술 용어**: 괄호 안에 보충 설명 `(BMR, Mifflin-St Jeor 공식 기반)` 식으로 처리
- **혜택 중심**: 기능 이름만 나열하지 않고, 사용자가 무엇을 얻는지 설명
- **클로징**: 항상 "의견은 언제든 환영합니다. 건강한 하루 되세요!" 로 마무리
- **분량**: 불릿 4~6개 권장 (App Store 4,000자 제한)

## 버전별 릴리즈 노트

### 1.2.0 — 맞춤 식단 추천 + 홈 위젯 (2026-06-30)

이번 업데이트로 무엇을 먹을지 고민이 줄고, 홈 화면에서 바로 오늘의 진행 상황을 확인할 수 있어요.

• 맞춤 식단 추천 추가 — 내 권장 칼로리와 단백질·탄수화물·지방 목표에 맞춰 끼니를 제안해드려요. 마음에 들지 않으면 대안 식단으로 바로 바꿀 수 있어요.

• 알러지·식단 제한 반영 — 프로필에 알러지나 못 먹는 재료를 등록하면 추천에서 자동으로 빼드려요. 확인된 정보만 사용해 안전하게 걸러요.

• 1회 제공량을 알기 쉽게 표시 — '사과 1개', '우유 200ml'처럼 실제 먹는 단위로 양과 영양소를 보여줘 식단 기록이 한결 편해졌어요.

• 홈 화면 위젯 추가 — 오늘 칼로리, 목표 진행률, 연속 기록(스트릭)을 앱을 열지 않고 홈 화면에서 바로 확인하세요.

• 추천 근거 안내 — 왜 이 식단을 제안했는지 이유와 주의 문구를 함께 보여드려, 믿고 선택할 수 있어요.

의견은 언제든 환영합니다. 건강한 하루 되세요!

### 1.1.1 — 소셜 로그인 + 영어 지원 (2026-06-04)

이번 업데이트로 로그인이 훨씬 빨라지고 앱이 영어를 지원해요.

• 소셜 로그인 추가 — Apple과 Google 계정으로 가입·로그인하실 수 있어요. 이메일 입력 없이 한 번에 시작하세요.

• 영어 지원 — 마이페이지 > 언어에서 한국어와 English 중 선택할 수 있어요. 처음 사용하시는 분의 지역과 시스템 언어에 맞춰 자동으로 설정돼요.

• 다크 모드 색감 정돈 — 목표 설정·신체 변화·정보 화면의 어색하던 검은 카드를 브랜드 톤(포레스트 그린)으로 통일했어요.

• 다양한 화면에서 날짜와 시간이 선택한 언어에 맞게 표시되도록 다듬었어요.

### 1.1.x — 영양 관리 업데이트

이번 업데이트로 영양 관리가 더 똑똑하고 투명해졌어요.

• 식단 입력 시 '오늘 남은 칼로리'를 바로 표시 — 얼마나 더 먹어도 되는지 한눈에 확인하세요. 권장량을 넘으면 경고 색으로 알려드려요.

• 식단 상세 화면에 '일일 권장량 대비' 진행률 추가 — 이 식사가 하루 권장 칼로리·단백질·탄수화물·지방에서 차지하는 비율을 막대그래프로 보여줘요.

• '왜 이 칼로리인가요?' 설명 추가 — 홈 화면에서 내 권장 칼로리가 기초대사량(BMR)·활동량·목표를 어떻게 반영해 계산됐는지 단계별로 확인할 수 있어요. (Mifflin-St Jeor 공식 기반)

• 프로필에 생년월일 입력·수정 기능 추가 — 더 정확한 맞춤 권장량을 받아보세요.

의견은 언제든 환영합니다. 건강한 하루 되세요!

### 1.2.x — 운동 기록 업데이트

이번 업데이트로 운동 기록이 더 정확하고 편리해졌어요.

• 운동 세트 입력 시 숫자 키보드에 '완료' 버튼 추가 — 무게·횟수·시간·거리를 입력하고 버튼 한 번으로 키보드를 닫을 수 있어요.

• 운동 검색 공백 무시 — '랫 풀다운'처럼 띄어쓰기가 달라도 '랫풀다운'으로 정확하게 찾아줘요.

• AI 운동 추정 정확도 향상 — 한국어 운동 이름(랫풀다운, 데드리프트, OHP 등)을 더 잘 인식하고, 운동 강도에 맞는 칼로리 소모량을 추정해줘요.

• 프로필에서 생년월일 입력 방식 개선 — 연도와 월을 피커로 빠르게 선택할 수 있어요.

• 대시보드·마이페이지 진입 시 오류 메시지가 잘못 표시되던 버그를 수정했어요.

의견은 언제든 환영합니다. 건강한 하루 되세요!
