1. **가공식품 API 자체가 ~2× 완전중복**: 286,989개 food_code 가 *정확히 동일한 행*(이름·품목보고번호·영양값 일치)으로 2번씩 등장(자체중복 49.4%). 가공식품만 단독 적재해도 절반이 잉여.
2. **음식 표준데이터(19,495)는 영양DB의 완전 부분집합**: 음식 코드 19,495개 = 100% 가 영양DB 코드와 겹침 → **음식 표준데이터는 별도 적재 불필요**(영양DB가 모두 포함).

5. **충돌 코드 3,961개는 전부 출처 간**: 같은 코드가 출처마다 다른 품목/영양값 → 코드 단순 병합은 위험, **출처 우선순위** 필요.
