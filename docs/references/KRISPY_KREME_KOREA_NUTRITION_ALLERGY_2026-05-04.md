## 3. 적재 전 정규화 메모

| 원문 요소 | 권장 내부 필드 |
|---|---|
| 브랜드 | `brand_name = "크리스피크림도넛"` |
| 구분 | `category` |
| 메뉴명 | `name` 또는 `name_ko` |
| 중량 | `serving_size_g`, 음료도 원문 단위가 g로 표기되어 우선 원문 보존 |
| 열량 | `calories_kcal` |
| 포화지방 | `saturated_fat_g` |
| 당류 | `sugar_g` |
| 단백질 | `protein_g` |
| 나트륨 | `sodium_mg` |
| 카페인 | `caffeine_mg` |
| 알러지 성분 | `allergens` 배열 |
| 고카페인 문구 | `warnings` 또는 `labels` |
| 공식 검증 상태 | `verification_status` |
