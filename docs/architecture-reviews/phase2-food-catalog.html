Deepen the admin catalog operation seam

Strong in-process

After

Caller
Admin Catalog Operation
auth, limits, audit, execution
importers
one interface, one place to test operation rules

Problem

The admin catalog module is shallow because its interface is just authenticated HTTP, while the implementation mutates large operational data.

Solution

Deepen admin catalog operations so authorization, page bounds, audit, and execution sit behind one seam.

Benefits

  • locality: operation rules concentrate
  • leverage: controller tests shrink
  • interface matches production risk

Problem

Imported refreshes can erase recommendation curation because the source adapter sends SEARCH_ONLY and updateFromImportedCatalog copies it.

Solution

Deepen curation so import updates source facts, while recommendation status changes through its own module.

Benefits

  • leverage: reimport stays safe
  • tests hit one interface
