# iOS ADRs

iOS 컨텍스트 ADR 인덱스입니다. SwiftUI 앱 구조, 상태 관리, 네비게이션, API client, 인증 상태, 기능 UI에 한정된 결정은 이 디렉터리에 기록합니다.

## Current ADRs

아직 iOS 전용 ADR은 없습니다.

## When To Add One

- 앱 네비게이션이나 화면 구조 변경
- 상태 관리, concurrency, API client 정책 변경
- 인증 세션/Keychain/refresh 흐름 변경
- 디자인 시스템이나 접근성 정책 변경
- 테스트 전략이나 Feature 모듈 경계에 관한 지속적인 결정

## Format

새 ADR은 `0001-short-title.md` 형식으로 추가하고, 최소한 다음 섹션을 포함합니다.

- Status
- Context
- Decision
- Consequences
